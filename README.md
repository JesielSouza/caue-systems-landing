   - Monograma geométrico `CS` com indicador dinâmico de status.
   - Relógio em tempo real de Manaus/AM (UTC-4).
   - Menu responsivo com drawer animado em Framer Motion.
2. **Hero Section:**
   - Efeito mesh ambient glow, títulos graduados e badges de posicionamento.
   - **Terminal Interativo Operacional (`InteractiveTerminal`)**: Simulação dos 4 ecossistemas reais (Sentinel Vision CCO, Virtus Flux Orchestration OS, Paperclip Lab Multi-Agent e Modular Showcase Engine 48h).
3. **Métricas Factuals (Stats Banner):**
   - Entrega em 48h, carregamento sub-0.8s, 99.9% de resiliência e 100% governança Human-in-the-Loop.
4. **Soluções & Pilares Estratégicos:**
   - Vitrines Modulares Express (48h), SaaS & Plataformas Operacionais, IA & Agentes Autônomos, Visão Computacional & CCO.
5. **Cases Reais & Portfólio Verificado:**
   - Filtros dinâmicos por categoria com animações de layout.
   - Modal detalhado de arquitetura e links em produção (Juliano Souza, Virtus Flux, Sentinel Vision, Vetra, Convés Digital).
6. **Metodologia (Pipeline Cauê de 5 Etapas):**
   - Diagnóstico factual, Design System, Engenharia Modular, Gate de Governança e Deploy Contínuo.
7. **Sobre Jesiel Souza:**
   - Perfil factual com histórico em CCO, monitoramento crítico, redes, CFTV e engenharia fullstack.
8. **Simulador de Briefing Interativo (WhatsApp Generator):**
   - O cliente configura o tipo de projeto, prazo, recursos desejados e gera a mensagem estruturada com disparo de confetes diretamente para o WhatsApp de Jesiel (`(92) 98103-8799`).
9. **FAQ Interativo:**
   - Accordion expansível em Framer Motion respondendo às principais dúvidas.
10. **CTA Final, Footer & Botão Flutuante do WhatsApp:**
    - Links rápidos, redes sociais (GitHub, LinkedIn), canais de atendimento direto e garantia de qualidade.

## 💻 Como Rodar Localmente

```bash
cd C:\Users\monit\caue-systems-landing
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no seu navegador.

### Build para Produção

```bash
npm run build
```

Os arquivos estáticos otimizados para deploy na Vercel serão gerados na pasta `dist/`.
